name: vethub:check-requirements
description: check vethub requirements
---

Check that the following tools have been installed and report:

- which java       # Should contain .local/share/mise (or similar mise path)
- which node       # Should contain .local/share/mise
- java -version    # Should show 25+
- node --version   # Should show 22+
- opencode --version # any version
- git --version    # any version
- cursor, code (vscode) # any ide
