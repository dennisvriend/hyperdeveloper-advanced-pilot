# When to use

Use when changing the database schema or seed data in `server/` (anything under `src/main/resources/db/changelog/`).

## Rules

- **All schema changes go through Liquibase** — never JPA `ddl-auto`.
- Changelog root: `src/main/resources/db/changelog/db.changelog-master.yaml`, which uses `includeAll` on `db/changelog/changesets/` — new changeset files placed in that directory are picked up automatically.
- Changeset file naming: `<yyyyMMddHHmm>-<ENV>-<slug>.xml` where ENV is:
  - `PRD` — production schema changes
  - `TST` — test/dev seed data
- XML format with raw `<sql>` blocks; every changeSet gets a `<comment>` and an `author`.
- changeSet id = filename + sequence suffix, e.g. `202610051200-PRD-visit-vet-attribution-1`.
- Set `logicalFilePath` to the filename so ids stay stable regardless of scan path.
- Never modify an already-applied changeset — add a new one instead.

## Configuration

- `src/main/resources/application.yml` — H2 in-memory, JPA + Liquibase enabled
- `src/main/resources/application-dev.yml` — dev profile (liquibase drop-first, basic auth)
- `src/test/resources/application-test.yml` — test profile (H2, drop-first, basic auth)

## Examples

Schema changeset (`changesets/202507101200-PRD-initial-schema.xml`):

```xml
<?xml version="1.1" encoding="UTF-8" standalone="no"?>
<databaseChangeLog xmlns="http://www.liquibase.org/xml/ns/dbchangelog"
                   xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                   xsi:schemaLocation="http://www.liquibase.org/xml/ns/dbchangelog http://www.liquibase.org/xml/ns/dbchangelog/dbchangelog-3.6.xsd"
                   logicalFilePath="202507101200-PRD-initial-schema.xml">

    <changeSet id="202507101200-PRD-initial-schema-7" author="jordi.jaspers">
        <comment>Creating visits table for veterinary visits.</comment>
        <sql>
            CREATE TABLE IF NOT EXISTS visits (
                id          INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
                pet_id      INTEGER      NOT NULL,
                date        DATE         NOT NULL,
                description VARCHAR(255),
                FOREIGN KEY (pet_id) REFERENCES pets (id)
            );
        </sql>
    </changeSet>
</databaseChangeLog>
```

Additive column change with FK (`changesets/202610051200-PRD-visit-vet-attribution.xml`):

```xml
<changeSet id="202610051200-PRD-visit-vet-attribution-1" author="dennis.vriend">
    <comment>Adding optional vet attribution to visits with ON DELETE SET NULL.</comment>
    <sql>
        ALTER TABLE visits ADD COLUMN vet_id INTEGER;
        ALTER TABLE visits ADD CONSTRAINT fk_visits_vet
            FOREIGN KEY (vet_id) REFERENCES vets (id) ON DELETE SET NULL;
    </sql>
</changeSet>
```

Master changelog (`db.changelog-master.yaml`):

```yaml
databaseChangeLog:
  - includeAll:
      path: db/changelog/changesets
```
